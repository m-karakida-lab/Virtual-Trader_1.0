# ADR-001: 損益表示はクオート通貨のまま、円換算しない

## 状況
EURUSD等のJPYを含まないペアを読み込むと、`(終値-始値)×lots` の計算結果はUSD等の値になる。これを常に円(¥)表示していたため「255pips獲得したのに+254円」のような誤解を招く表示になっていた。修正方針を検討した。

## 決定
損益・残高は **読み込んだペアのクオート通貨のまま表示する**（USD/EUR/JPY等、ファイル名から検出した記号をそのまま付ける）。実際の為替レートを使った円換算は行わない。

## 理由
- MT4/MT5等の実プラットフォームは「口座通貨」を固定して都度レートで自動変換しているが、このアプリは1ペアのCSVしか読み込んでおらず、変換用のレートを持つデータソースがない
- 固定レートを手入力する方式も検討したが、「だいたい合ってるっぽい数字」を作るだけで誤差が乗り、わがままツールの価値（正確な検証）を損なう
- JPYクロス専用に限定する案もあったが、EURUSD等も普通に検証したいというユーザーの実需に合わない

## 影響
- 初期残高のデフォルトも通貨に応じて変える（JPY=100万、それ以外=1万）。`defaultBalanceFor()` 参照
- 新しい通貨ペアを追加する場合、`src/lib/currency.ts` の `CURRENCY_SYMBOLS` に記号を追加するだけでよい
- 将来複数ペアを同時に読み込んでクロスレート換算したくなった場合は、この方針自体を見直す必要がある
